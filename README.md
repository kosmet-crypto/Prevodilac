# Преводилац српски ⇄ норвешки

Веб апликација за превођење између српског и норвешког (bokmål) **у духу језика**,
прилагођена твом нивоу норвешког по CEFR скали (A1–C2). Превођење ради Claude
(Anthropic Messages API).

## Шта апликација ради

- **Превод у оба смера**: српски → норвешки и норвешки → српски, са дугметом ⇄ за
  замену смера. Српски улаз може бити на ћирилици или латиници; за превод на српски
  бираш писмо (ћирилица/latinica).
- **Ниво норвешког (CEFR A1–C2)**: превод на норвешки користи речник и граматику
  изабраног нивоа (на A2 кратке реченице и основне речи, на C1 богатији речник,
  идиоми и сложеније конструкције). Испод дугмади је кратак опис сваког нивоа.
  У смеру норвешки → српски ниво одређује колико детаљно се објашњава граматика.
- **За сваки превод приказује**:
  - **Природан превод** — како би то рекао изворни говорник, а не реч по реч;
  - **Буквалан превод** — дословно, да се види структура;
  - **Фразе и идиоми** — оригинал, буквалан превод, еквивалент у другом језику
    (нпр. „пала ми је секира у мед“ → *å ha flaks*) и кратко објашњење кад се
    користи. Ако еквивалента нема, то пише, уз најприроднији опис;
  - **Напомене** о граматици, реду речи (V2), регистру (du/dere, формално/неформално)
    и речнику кад помажу да се схвати превод.
- **Историја превода** (последњих 50, чува се у прегледачу), **копирање** превода и
  **изговор** норвешког текста преко Web Speech API-ја (глас `nb-NO`, ако га
  прегледач/систем има).
- Интерфејс на српском, прилагођен телефону, светла и тамна тема.

## Како да добијеш Claude API кључ

1. Отвори [console.anthropic.com](https://console.anthropic.com) и направи налог (или се пријави).
2. У делу **Billing** додај начин плаћања или кредит (API се наплаћује по потрошњи,
   одвојено од Claude.ai претплате).
3. Иди на **Settings → API keys** ([директан линк](https://console.anthropic.com/settings/keys)),
   кликни **Create Key** и копирај кључ (почиње са `sk-ant-`).
4. У апликацији кликни ⚙️ (подешавања), налепи кључ и сачувај.

**Безбедност:** кључ се чува само у `localStorage` твог прегледача и шаље се
искључиво директно на `api.anthropic.com`. Није у коду ни у репоу. Свако ко има
приступ твом прегледачу може да га прочита, зато не користи апликацију на туђем
рачунару (или кликни „Обриши кључ“ у подешавањима кад завршиш). Препорука: у
конзоли постави месечни лимит потрошње за кључ.

## Модел

У подешавањима бираш модел. Подразумевано је **Claude Opus 5.5** (`claude-opus-5-5`),
најновији модел. Ту су и Sonnet 5.5 (бржи и јефтинији), Haiku 4.5 (најбржи и
најјефтинији) и Fable 5.1 (најмоћнији и најскупљи), а можеш унети и било који други
ID модела.

Модел враћа одговор као JSON по фиксној шеми (`output_config.format`), па га
апликација приказује по одељцима.

## Покретање

Нема build корака, само статички фајлови (`index.html`, `style.css`, `app.js`).

- **Локално:** отвори `index.html` у прегледачу, или покрени мали сервер:
  ```bash
  python3 -m http.server 8000
  ```
  и отвори <http://localhost:8000>.

### GitHub Pages

1. На GitHub-у отвори репо → **Settings → Pages**.
2. Под **Build and deployment → Source** изабери **Deploy from a branch**.
3. Изабери грану (нпр. `main`, или радну грану) и фолдер **`/ (root)`**, па **Save**.
4. После минут-два апликација је на `https://<корисничко-име>.github.io/Prevodilac/`.

Фајл `.nojekyll` је ту да GitHub Pages сервира фајлове онакве какви јесу.

## Структура

| Фајл | Шта ради |
|---|---|
| `index.html` | изглед странице и дијалози (подешавања, историја) |
| `style.css` | стил, светла/тамна тема, прилагођавање телефону |
| `app.js` | логика: CEFR нивои, позив Claude API-ја, приказ, историја, изговор |
