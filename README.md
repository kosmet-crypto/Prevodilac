# Преводилац српски ⇄ норвешки

Бесплатна веб апликација за превођење између српског и норвешког (bokmål). Нема
регистрације, API кључа ни плаћања.

## Шта апликација ради

- **Превод у оба смера**: српски → норвешки и норвешки → српски, са дугметом ⇄ за
  замену смера. Српски улаз може бити на ћирилици или латиници. За превод на српски
  бираш писмо (ћирилица/latinica).
- **Машински превод** иде преко бесплатног сервиса [MyMemory](https://mymemory.translated.net).
  Ако база има више превода, приказују се и „други преводи из базе“.
- **Фразе и идиоми**: уграђени речник од око 70 српских и норвешких израза. Ако
  се израз нађе у тексту, апликација га приказује са:
  - буквалним преводом;
  - еквивалентом у другом језику (нпр. „пала ми је секира у мед“ → *å ha flaks*),
    или ознаком да еквивалента нема, уз најприроднији опис;
  - кратким објашњењем кад се користи;
  - CEFR нивоом израза (A1–C2).

  Речник ради и без интернета.
- **Напомене** о граматици и регистру кад их текст „покреће“: du/dere, обраћање
  са „Ви“, ред речи V2, место речи „ikke“.
- **Историја** (последњих 50 превода, чува се у прегледачу), **копирање** превода и
  **изговор** норвешког текста преко Web Speech API-ја (глас `nb-NO`, ако га систем има).
- Интерфејс на српском, прилагођен телефону, светла и тамна тема.

## Ограничења

- Бесплатни машински превод је често дослован и греши код идиома. Зато је ту
  речник фраза, али он препознаје само изразе које садржи.
- Превод се не прилагођава CEFR нивоу. Ниво је приказан само уз изразе из речника.
- MyMemory без налога дозвољава око 5000 знакова превода дневно (по интернет
  вези). Кад се лимит потроши, апликација то напише. Фразе и напомене раде и тада.
- Један превод може имати највише 1000 знакова.

## Покретање

Нема build корака, само статички фајлови.

- **Локално:** отвори `index.html` у прегледачу.
- **GitHub Pages:** репо → **Settings → Pages** → **Deploy from a branch** → изабери
  грану и фолдер **`/ (root)`** → **Save**. После минут-два апликација је на
  `https://kosmet-crypto.github.io/Prevodilac/`.

## Структура

| Фајл | Шта ради |
|---|---|
| `index.html` | изглед странице и историја |
| `style.css` | стил, светла/тамна тема, прилагођавање телефону |
| `app.js` | превод (MyMemory), ћирилица ⇄ латиница, напомене, историја, изговор |
| `idioms.js` | речник фраза и идиома, лако се допуњује новим изразима |
